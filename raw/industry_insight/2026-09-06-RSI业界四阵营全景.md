# RSI 业界四阵营全景

**整理日期**：2026-09-06
**来源**：多篇报道综合（见文末），非单一原文

## 背景锚点数字

Anthropic 披露：截至2026年5月，Claude Code 生成的代码已占公司生产代码库新增部分的**80%**（2025年2月刚发布时不到5%）——目前最扎实的、可验证的实证数字，不是预测。

---

## 一、警报派：Yoshua Bengio——直接呼吁暂停

图灵奖得主、深度学习奠基人之一。表态比 OpenAI 的 Pachocki 更硬："**如果头部AI公司真的在接近RSI临界点，一次协调的、可验证的、全球统一执行的暂停，可能是唯一负责任的解法——至少要等到安全保障建立起来。**"目前业界最激进的"停下来"主张。

## 二、Anthropic 内部分裂——概率预测 vs 克制表态

Anthropic 自己内部不是铁板一块：

- **联合创始人 Jack Clark** 给出具体概率：真正的RSI，**2027年前发生概率约30%，2028年前约60%**——不少研究者认为这个估计太激进
- Clark 和 **Anthropic Institute 负责人 Marina Favaro** 联合发文态度又谨慎："我们还没到那一步，RSI 不是必然的，但它可能比大多数机构准备好的时间来得更早"
- Clark 还指出一个具体的技术悲观信号："AI系统里明显缺乏有价值的、直觉性的创造力"，称之为"对短期RSI时间线的看跌信号"——同一个人既给出激进概率数字，又亲口承认技术上有硬伤，立场本身就很分裂

## 三、技术怀疑派——普林斯顿研究：AI 现在只会"工程"，不会真正做研究

最扎实的反方证据。普林斯顿研究者 **Sayash Kapoor** 的研究发现：AI agent 擅长工程任务，但一碰到需要判断力的开放式研究就现原形——"跑出稀奇古怪的实验"、"没有任何新颖贡献"。具体缺陷：

- 探索不足，太快锁死在没前途的方向上
- 只能做小修小补，没法从根本上重新思考方案
- 不会有效利用token/算力/时间这些资源
- 拿到反馈后不会真正采纳，只会缩小自己的论断范围

**根本原因**：现在的强化学习擅长训练"有客观评分标准"的任务，但开放式研究没有这种标准，没法造出训练环境去教它。

**Peter Wildeford 采访了25位AI研究者**，其中 **16人对"positive feedback"或"recursive"这个核心环节表示怀疑**——但同时"不少领先的AI研究者真心相信，具备递归改进能力的AI也就还有几年时间"，理由是 METR 的任务时限基准、scaling law 这些趋势线还在涨。

## 四、定义批判派——TechCrunch：RSI 正在变成第二个"AGI"

作者认为 **RSI 正在变成第二个"AGI"**——一个人人在用、但谁也说不清楚具体指什么的词。不同人的定义完全不是一回事：

- **大多数实验室的朴素版本**：系统能不靠人自己持续升级，闭环只受算力限制
- **Richard Socher 的 Recursive Superintelligence**：从"想点子"到"实现"到"验证"整个研究流程全自动化
- **Andrej Karpathy 的 Auto-Research**：更保守，RSI就是通过训练agent做"小修小补"，不是戏剧性突破
- **Helen Toner 的三段论框架**：区分 **adequacy**（系统不靠人能跑通）、**parity**（做研究质量追平人类）、**supremacy**（超越人机协作）——这三个阶段完全是不同量级的主张

**这个批评的重要性**：当每个人用的"RSI"标准都不一样时，"我们离RSI还有多远"这种问题本身就是个假问题——没有共同基准，就没法区分真实进展和营销话术。

## 与庆祝派/警报派二元框架的关系

原有的 Anthropic（庆祝）vs OpenAI（警报）二元对照，只是这个更大光谱的两个极端点。完整光谱至少包含四个维度：
1. **情绪基调**：庆祝（Dario）↔ 警报（Bengio、Pachocki）
2. **概率预测的自信程度**：具体激进数字（Jack Clark 的30%/60%）↔ 承认不确定（Favaro/Clark 联合声明）
3. **技术判断**：有创造力缺陷的实证证据（Kapoor 普林斯顿研究）↔ 趋势线仍在涨的乐观（METR benchmark 支持者）
4. **元层面**：连"RSI"定义本身都没有共识（Toner 三段论框架、TechCrunch 批评）
