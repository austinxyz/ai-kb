# KAIROS 自主守护进程

#concept #AI #AgenticAI #ClaudeCode

> 一句话定义：Claude Code 中的 always-on 后台代理模式，在用户空闲时自主进行记忆整合与项目理解更新。

---

## 核心原理

命名来自古希腊语"恰当的时机"。KAIROS 让 AI 编程助手从响应式工具进化为持续协作者：不需要用户发指令，代理自动在后台运行，合并零散观察、消除逻辑矛盾、将模糊洞察固化为确定性事实（autoDream 逻辑）。

## 关键要素

- **autoDream**：用户空闲时触发的记忆整合逻辑，主动发现并修复知识库中的矛盾
- **守护进程模式**：不依赖用户交互持续运行，类似操作系统后台服务
- **产品形态跃迁**：从"你问我答"→"持续理解你的项目、主动发现问题"
- 目前仍是 Claude Code 未上线的 feature flag 之一
