## 摘要

2026年3月31日，Anthropic 意外在 npm 包中泄露 Claude Code 完整 TypeScript 源代码（51.2万行）。极客公园从产品策略视角分析：中国 AI 公司的差距不在"能不能用"，而在工程精细度，并提出四条可学习的方向。

## 关键要点

- **工具描述就是产品力**：每个工具的 prompt 描述精细调优（何时用、何时不用、出错如何重试），同一模型因此表现提升一个档次
- **三层记忆架构**：热数据（MEMORY.md 索引）始终在线 → 温数据主题文件按需加载 → 冷数据（对话记录）只做 grep 检索；解决上下文窗口有限问题
- **情绪感知是工程问题**：用正则表达式（frustration regex）检测用户发火，不需要大模型推理，快且省钱——启示：不是所有问题都要丢给大模型
- **KAIROS 守护进程**：always-on 后台代理，用户空闲时自动整合记忆、消除矛盾；指向下一代产品形态——从"响应式工具"到"持续理解项目的协作者"
- **抄的边界**：直接 fork 有版权风险；真正该学的是每个设计决策背后的 tradeoff，针对自己的模型特点重新实现
