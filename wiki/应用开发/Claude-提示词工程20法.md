## 定义

面向普通用户的 20 个结构化提示词模板，覆盖研究、写作、职场、日常生活、学习五大场景，核心是"角色+任务+约束+输出格式"四层结构。

## 核心要点

**深度研究**
- **多源融合**：强制跨文章综合（禁止逐篇总结），输出：核心共识 / 关键冲突 / 核心盲区 / 最强论点 / 落地建议
- **魔鬼代言人**：让 Claude 单纯批判不提建议，从漏洞假设 / 执行风险 / 市场现实 / 致命硬伤四维攻击；"一句话最致命反对理由"收尾
- **Steelman**：为对立观点构建最强版本，目标是"终于明白聪明人为什么相信这个"
- **思维模型构建**：3-5 个关联模型 + 各自常见误区 + 模型间相互关联 + 最后出一道测试题

**写作**
- **文风复刻**：喂 3 篇样本 → 剖析节奏/词汇/开头/收尾/禁忌 → 生成新内容，目标是不改直接发布
- **铁血主编**：给出删减清单 / 软弱观点 / 缺失内容 / 结构问题 + 直接改写，禁止先夸再改
- **一稿五用**：同一内容改写给零基础/专家/杠精/记者/高管，揭示哪个最难写好

**职场**
- **谈薪沙盘**：HR 角色扮演至少抛 3 个真实拒绝理由，复盘时给出"最有效一击"
- **面试模拟**：覆盖 STAR/技术/危机/跨职能问题，逐题给出亮点 + 盲区 + 满分范本
- **艰难对话排练**：开场白 + 对方 3 种回应 + 应对方案 + 雷区 + 完美收尾五件套

**学习**
- **费曼学习法**：单概念教学 + 即时测试，答错时换比喻不重复，最后让学生复述
- **苏格拉底式**：全程只问问题不给答案；只有学生能用自己的话说出核心洞察才结束

**底层结构规律**：所有模板都包含"角色设定 + 禁止项（防止 AI 走套路）+ 结尾的元认知要求（哪个最难/最致命的X）"
