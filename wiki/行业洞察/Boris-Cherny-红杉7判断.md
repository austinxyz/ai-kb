## 定义

Claude Code 创始人 Boris Cherny 在红杉资本大会上提出的 7 个关于 AI 重塑软件工程的结构性判断，涵盖代码稀缺性、工程师角色、SaaS 护城河、MCP 定位、Computer Use 价值等核心议题。

## 核心要点

1. **代码不再稀缺**：工程师价值从"会不会写"转向"会不会拆任务 / 讲清目标 / 验收结果 / 管理 Agent"；类比工业革命——流水线出现后值钱的不是手工艺人而是流水线设计者

2. **像古登堡印刷机**：AI 对软件的影响 = 加速版印刷术革命；Boris 预测软件会在几十年内民主化，"会做软件像会发短信一样自然"

3. **最重要能力是判断力**：AI 抹平执行门槛后，产品感觉和领域深度的差距被放大；未来 generalist = 跨学科全栈（产品+设计+工程 / 产品+数据+工程），Claude Code 团队所有角色都在写代码

4. **SaaS 护城河瓦解**：切换成本护城河（数据迁移）和工作流锁定护城河，在强模型面前均开始崩塌；Opus 4.7 类模型最擅长"读懂复杂流程→拆解→在新环境重建"；这是 SaaS 新玩家的机会窗口

5. **创业者最好的时代**：未来 10 年颠覆性创业公司可能是过去的 10 倍；大公司历史负债（流程/岗位/培训/KPI）是 AI 落地的阻力，小团队无历史包袱；AI 越强，小团队加速度 vs 大公司拖拽力的"剪刀差"越大

6. **MCP 不会死**：API = Human Developer Interface（给人用）；MCP = Model Interface Protocol（给模型用）；移动互联网时代"所有服务 API 化"→ AI 时代"所有服务 MCP 化"

7. **Computer Use 依然重要**：企业核心系统大量没有 API、没有文档、无法重构；Computer Use 是无 API 系统的唯一落地路径，解决企业落地最大痛点
