## 核心术语速查

| 术语 | 定义 |
|------|------|
| **AI Native Infrastructure** | 以模型为执行主体、算力为稀缺资源，实施从意图到消耗到结果的闭环治理 |
| **Model-as-Actor** | 模型作为具有工具调用能力的可执行 Agent，需要治理 |
| **Compute-as-Scarcity** | GPU、互联网络和电力成为主要瓶颈，成本具有非弹性 |
| **Uncertainty-by-Default** | Agentic 场景下行为和资源消耗高度不可预测 |
| **Intent Plane** | 表达策略和优先级的层 |
| **Execution Plane** | 训练/推理/服务的执行层 |
| **Governance Plane** | 配额/预算/隔离的治理层 |
| **The Loop** | 准入 → 翻译 → 计量 → 执行的闭环 |
